# 视觉 token 说明

本版视觉方向是 light editorial / gallery：大量白色留白、衬线展示标题、细线分区、低饱和墨色和一个克制的编辑部强调色。目标是让小程序像一本安静的策略杂志或展厅目录，而不是默认产品模板。

## Token

- 背景：`#FFFEFA`，页面再叠极淡暖灰和墨红径向光感。
- 轻背景：`#F8F5EE`
- 主文本：`#1C1713`
- 次级文本：`#71675E`
- 弱文本：`#AAA096`
- 分隔线：`#E8E1D6`
- 强分隔线：`#CFC4B6`
- 强调色：`#9B3A2F`
- 强调浅底：`rgba(155, 58, 47, 0.08)`
- 墨色主按钮：`#17130F`
- 展示标题字体：`Songti SC / STSong / SimSun / Georgia / Times New Roman / serif`
- 正文字体：系统无衬线，中文走 `PingFang SC` / `Microsoft YaHei` 回退。
- 字号：20 / 24 / 28 / 32 / 36 / 40 / 48 / 60 / 76 rpx。
- 间距：8 / 12 / 16 / 24 / 32 / 48 / 72 / 104 rpx。
- 圆角：6 / 12 rpx，按钮使用胶囊形。
- 阴影：浅色背景上的极淡暖灰环境阴影。

## 组件规则

- 首页只放标题、副标题、按钮。
- 结果页不使用头像、图标、卡图。
- 只保留一个强调色，主 CTA 使用墨色而非高饱和蓝色。
- 页面用留白、细线和排版层级建立层次，少用重投影。
- 标题和推荐名使用衬线字体，正文和操作控件使用系统无衬线。
- 图表使用细线、墨红强调和暖灰坐标，不加多余装饰。
- 背景微尘改为偏纸面暖调，不使用光束或强粒子效果。
