# 赛事月报

`pages/meta/meta` 默认展示赛事月报，原有署名梯度保留在小屋编辑榜。云函数 `metaMonthly` 在现有环境和 `community` 集合内使用 `meta_monthly_` 命名空间；客户端仍不能直接读写集合。月报不参与 Bracket 规则判定。

## 数据与计算

数据来自 [TopDeck V2 API](https://topdeck.gg/docs/tournaments-v2)，主将以 Scryfall Oracle ID 归一化，拍档顺序不影响合并。公开数据免费展示并署名，API key 仅在服务端使用。

月报以 UTC 月末为截止，取开赛日期落在此前 90 天且实际完赛早于截止的赛事。要求 EDH、至少 50 名实际参赛者、至少四轮瑞士轮、主将覆盖率和四人桌比例均不低于 80%。排除团体、联赛和名称明确标记的预组、贫民、特殊规则赛事。名称过滤不能辨识所有自定义赛事，排除原因与覆盖率随快照保留。

瑞士轮只统计四人已完成牌桌。和局使用 API 明确的 Draw 标记；Unknown 不当成和局。轮空与淘汰轮不进入胜率。晋级名单必须由全部淘汰轮实际参赛者并集验证，不能直接把最终名次前 N 名当成晋级者。

模型 `relative-performance-v1`，基准分为 50。令全样本胜率为 μ、晋级率为 q，某组合的瑞士轮胜场 W、对局 G、晋级 K、按各赛事名额比例累计的预期晋级数 E：

```
p = (W + 80μ) / (G + 80)
c = (K + 40q) / (E + 40q)
score = 25 × (p/μ + c)
```

胜率与晋级表现等权，出场占比单独展示。80 对局、40 次参赛是本版本固定的收缩参数，未宣称是经优化的最优参数。按赛事聚类重采样 240 次，使用固定全样本基准，取 95% 分位区间。它衡量已观测样本的不确定性，不是未来胜率预测。

分档要求至少 20 次参赛、5 位独立牌手、3 场赛事和 20 次可验证晋级机会。区间完全高于 50 为领先，跨 50 为竞争，完全低于 50 为承压；其余进入观察中。跨期变化只在模型版本相同时计算。参考 Lemora’s Cards 的等权思路，使用本项目自行实现、可复算的模型。

## 自动运行与恢复

`config.json` 的 timer 为 `0 17 * * * * *`，北京时间每小时第 17 分钟执行。UTC 每月前三天宽限结束后采集上一月，完成后当月后续触发仅检查状态。每次最多验证四场赛事，遇到限流/网络失败保留旧月报并从游标重试。事务租约防重入；每场赛事完成即落检查点。

发布顺序是写不可变快照、读回校验、事务切换月份索引。失败不会替换已发布数据；历史回填不会把最新月份倒退。前端校验结构、缓存六小时，断网显示已保存月报与重试状态。公开快照不含牌手 ID；私有检查点只保留散列标识，不采集姓名或联系方式。

## 部署

1. 本机用户级 `TOPDECK_API_KEY` 已配置。另创建至少 32 字符的随机 `META_ADMIN_TOKEN` 用于维护操作。两者均不进入 Git、聊天或前端。
2. 将 `cloudfunctions/metaMonthly` 复制到私有临时目录，并仅在该目录生成忽略文件 `runtime-secrets.json`，字段 `topdeckKey`、`adminToken`。支持用服务端环境变量替代该文件。
3. 使用官方 DevTools CLI `cloud functions deploy --env cloudbase-d6gvqujh4d0efe37f --paths <临时目录>/metaMonthly --project <实际开发工程> --remote-npm-install`。在原生云开发控制台将超时设为 60 秒、内存保留 256 MB。CLI 代码上传不会创建触发器，需在实际工程中右键本函数的 `config.json`，选择「上传触发器」，再到云函数详情刷新确认线上规则。
4. 维护端可调用 `status` 查看进度、失败次数与最近定时触发时间。维护端调用 `seed` 发布随函数携带的历史回填，再调用 `tick` 实测检查点。普通调用只允许 `get`；伪造 event.Type 或 action 不产生维护权限，定时任务通过服务端 SOURCE 判断。
5. 删除本次私有部署暂存。用公开 `get` 验证月份、哈希、覆盖率和列表，再验证小程序的搜索、筛选、详情、缓存和离线状态。

本地回填命令需显式指定私有缓存位置，缓存保存赛事原始 API 数据，不进入仓库：

```
node scripts/build-monthly-meta.js --period 2026-10 --cache <私有目录> --output <聚合快照.json>
```

当前复用已付费 CloudBase，无新增订阅或付费 API。调用量、计算量仍记入原套餐；没有设置自动购买或升级套餐。
