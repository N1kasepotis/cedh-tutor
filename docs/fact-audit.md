## 当前快照与含义边界

- **赛事**：2026-10-06 从 EDHTop16 当前站点公开查询取得 652 条记录，窗口为最近六个月、赛事至少 50 人；100 位本地主将全部匹配。各正数条目的 `entries / metaShare` 对应同一分母 17,625。该分母来自比值一致性，不是本站 100 人列表合计；源列表条目合计不覆盖全部份额的原因未独立确认。另完整读取全部 100 位主将的参赛记录，以 `sum(wins) / sum(wins + losses + draws)` 复算，100/100 与源值一致。Hashaton 为 35 胜 / 85 负 / 37 平，`35 / 157 ≈ 22.293%`；排除平局会得到不同结果。这里指源记录报告的胜负平，不额外声称它们都对应实际打完的牌局。[汇总凭据](audits/edhtop16-win-rates-2026-10-06-b5a7629f6e03.json)不含牌手身份；元数据保存其 SHA-256。公开站点的查询协议与这次观察不是永久接口承诺，后续刷新只有加 `--verify-games` 并全量一致才标注已复算。
- **组合技**：当前 Spellbook API 共遍历 4,035 条双卡记录，筛选并去重为 3,086 组配对，涉及 1,853 张牌；全部配对反查成功。字母标签是社区定性指南，可能被编辑覆盖；映射与至少 B3 的内容基线是工具策略。快照只保留配对和分类，不能验证配方额外条件已在实际游戏中满足，也不是官方判决或实战校准。
- **Planechase**：当前 Scryfall 的 MOC 简中集合仍为 45 时空 / 5 异象；全部 50 张印次的中文名称、类型、文字与身份无差异；另取得并阅读全部 50 张英文 Oracle。特殊动作费用、异象状态动作、同时换出多时空、开局不触发，与当前 CR 901 / 704.6f 一致。四张特殊牌的来源实例、副本、追加和展示处理已复核；其余生物、支付、目标与实体牌桌触发由牌桌处理，应用不是完整堆叠引擎。
- **起手练习**：核对了 Play to Win 视频字幕的八手对应牌张、座次及结论，TopDeck 文章的两种案例结论与调度阶段。视频中的“三分之一”来自当时牌表的估算，不是任意 Kinnan 牌表的概率；Esper Sentinel 抓牌数量取决于对手施放和付费。题目展示来源观点，不是最优策略证明。已打开原文两幅图片核对七张牌；第二例以原文的 Rhystic Study 名称记录该效应。
- **梯度与推荐**：梯度来自已有人工编辑快照，属于编辑观点。推荐、主题轴、B4.5/B5 和相关阈值是启发式；百分数展示是相对缩放，不是未来胜率、判断准确率或玩家人格分布。测试覆盖可达性与函数算例，不证明竞争力或心理测量效度。
- **随机**：骰面与抽签按等机会随机源建模；运行时使用 `Math.random`，不是可验证的物理随机或密码学随机。组合数概率针对从给定池不放回抽取的条件模型；不代表社区的牌表组成。
- **手动试玩**：按区段导入、洗牌、抽牌和手动跨区操作，不自动执行支付、London 调度、失败抽牌的败北、统帅区返回或完整 Commander 合法性；统帅区容量是界面容量，不是合法主将数量规则。
