# 预商业化产品与工程审查

日期：2026-09-05；审查基线 `6b575f3`。结论：Planechase 的本地实现已完成本轮加固；整个产品尚不具备完整的商业发布证据。测试通过和界面整齐都不能代替规则校准、真机验证与发布控制。

## 假设与成功条件

保留原生微信小程序、13 页、8 个首页入口及现有品牌。当前由工程审查与规则复核完成，不假定已获得 15 人评审团队的批准。竞品名单、目标设备、上线日期、人员投入和预算均为 TBD；本轮没有新增付费服务。

产品价值来自可靠地完成牌桌任务。一个链路要同时满足：输入被正确理解、依据可信、状态转换合法、失败能恢复、呈现不误导、结果可验证、发布后能追查和回退。任何关键环节失败都不能用视觉得分抵消。

## 全链路发现与决策

| 环节 | 发现与影响 | 决策 / 当前状态 | 后续负责人 |
|---|---|---|---|
| 入口与产品结构 | 首页与工具页承担不同任务；多种品牌表现不应导致相同动作行为不一致 | 保留首页索引与混沌工具下的 Planechase；高频动作、状态和撤销先统一 | 产品 + 设计 |
| 输入 | Bracket 与 Playtest 使用不同解析路径；无显式统帅区输入在 Playtest 有猜测行为 | 待办：共享规范化牌表模型，显示统帅候选并允许确认；不要直接合并两个解析器后假定语义一致 | 工程 + 规则 |
| 判断依据 | Bracket 包含自有结构、价格及主将池启发式；价格 >$1500 等条件可参与 B5 升档 | 待办：以专家盲评牌表校准。明确区分官方约束与本项目估计；避免价格或知名主将替代强度证据 | 规则 + 产品 |
| 推荐 | 基准画像覆盖 100/100，但“都能被推荐”不等于“推荐准确、有帮助” | 待办：用实际玩家意图与独立标签做准确性/解释质量评审，不将可达率包装为模型准确率 | 产品 + 数据 |
| 外部数据 | Meta、Spellbook、牌面、禁牌和规则的来源、更新时间、用途不同 | 待办：统一来源、版本、有效期、覆盖缺口的展示与更新责任；保留 Meta 与强度判定的隔离 | 数据维护者 |

| 运行状态 | Planechase 原页面可在掷骰中切后台后留下 rolling=true 且没有计时器；旧测试没覆盖 | 已改为可持久化的独立操作记录，移除对计时器提交的依赖 | 已完成本轮工程实现 |
| 规则执行 | Norn、Saulvinia、复制遭遇/换境、异象状态动作不能用单一阶段替代 | 已修复并经独立反证；详见 planechase-review.md | 规则负责人仍需正式验收 |
| 数据恢复 | Playtest 保存牌表与法术力，但完整战场、牌区、生命、指示物没有跨重开保存 | 发布阻断项：补完整对局恢复与迁移测试。不能把“保存牌表”当作“保存对局” | 工程 + QA |
| 视觉系统 | Planechase 原来导入主题但不在根选择器中；存在无效边框声明；其他页仍有局部色值/字体债务 | Planechase 与共享边框修复；Bracket 等页面下一轮逐类归并语义 token，避免盲目全站换色 | 设计 + 前端 |

## 15 人评审建议

以下是待确认的评审设计，不是已经取得的用户研究结果。

建议分 5 组、每组 3 人：规则正确性、恢复/异常、交互/无障碍、数据/解释、发布/工程。交叉复核时交换分组，避免作者同时担任最终验收人。每位评审使用相同任务与固定输入；本产品与竞品交替先后顺序，记录步骤与失败证据，隐藏品牌后再做信息理解评价。

| 比较任务 | 记录方式 | 建议硬门槛 |
|---|---|---|
| 找到工具并完成第一次普通掷骰 | 成功/失败、操作数、时间、误解原话 | 所有人无需口头教学完成；不允许错误费用或无反馈点击 |
| Norn / Spatial / Saulvinia / Aether 连续互动 | 逐步期望牌区、来源、骰面修正及截图 | 指定关键规则场景 100% 正确 |
| 复制触发、反击、响应换境 | 对照事件顺序与来源身份 | 不吞能力、不重复能力、不跳过状态动作 |
| 操作中切后台、杀进程、重开 | 保存前后快照对比 | 已确认保存的状态 0 丢失；恢复后能继续同一步 |
| 断网、卡图失败、存储配额不足 | 可恢复路径和用户对状态的判断 | 规则文字可读；不得显示未保存结果为已提交 |
| 同牌表进入 Bracket 与 Playtest | 统帅、数量、区段、警告和原文对照 | 关键输入含义一致，歧义可修正 |
| Bracket 专家盲评 | 固定牌表、独立结论、分歧原因 | 验收阈值 TBD；严重误判不靠总分平均掉 |
| 窄屏、大字体、长牌文、双时空 | 实测边界、遮挡、热区、读屏顺序 | 关键操作可达、文字不丢失、无横向溢出 |

竞品版本、设备型号、微信版本、网络条件及脚本版本必须随记录保存。时间/满意度等指标先测基线，再确定改进阈值；不预造领先百分比。

## Definition of Done

代码审查本轮：全仓阅读结论归档；Planechase 修复可复现、可测试；README 更新；语法、测试、严格诊断与原生模板编译通过；未把浏览器预览写成真机验收。

产品正式放行：上述发布阻断项关闭；指定关键流程全部通过；P0/P1 为 0；竞品对比问题由独立负责人复核关闭；正式域名、授权、包体、性能与回滚有记录；评审团队批准固定版本；试用复盘负责人和收集方式已确定。
