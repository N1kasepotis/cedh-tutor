# Planechase 规则、恢复与界面审查

审查日期：2026-09-05。基于主线 `6b575f3`；实现位于 `codex/planechase-hardening` 工作树。

## 结论与范围

本次把 Planechase 从依赖页面动画的工具，改为先保存、后提交的共享时空套牌操作记录。规则正确性、存档完整性和玩家对当前步骤的理解共同构成验收条件。当前结果可以进入产品与规则评审，尚未完成真机发布验收。

假设：沿用原生微信小程序、现有品牌与混沌工具入口；默认 MOC 官方简中 50 张；支持 2–5 人；本机存储；不引入付费服务、云端账户或运行时大模型。它不模拟玩家战场、法术力支付、优先权和全部 MTG 堆叠，玩家负责按实际堆叠顺序选择下一项结算。

## 从输入到结果的约束

| 环节 | 必须满足的条件 | 本次实现与证据 |
|---|---|---|
| 数据来源 | 不把英文回落、缺页或重复身份当作完整中文牌库 | 构建前验证 50 张、45/5 分布、中文字段、唯一印次和 Oracle ID、三档 CDN 地址；网络有超时、有限重试及分页边界 |
| 卡片身份 | 数据重排不能变更既有牌局 | schema 2 使用 Oracle ID；v1 下标经过冻结的旧身份表迁移；重排回归测试 |
| 物件身份 | 同一张异象再次进入后是新对象 | 每次换入记录 visit；遭遇触发及副本保留各自的 visit，旧实例不阻塞新实例的状态动作 |
| 牌库 | 任一有效状态中，每张牌恰好位于一个区 | 活跃时空、牌库、人数裁剪一致性验证；3,000 步持久化流程测试及原有 2,000 步内核测试 |
| 掷骰 | 特殊动作费用与效应掷骰分开；结果不自动跳过堆叠 | 普通掷骰只在页面待办清空后开放；效应掷骰不增加普通次数；PW 和混沌生成独立来源 |
| 结算 | 反击、复制及离场来源不丢失；状态动作先于下一项能力 | 独立 triggers 列表；复制时保留来源实例；异象 exit 优先于其他待处理能力 |
| 展示/置底 | 任意顺序不等于随机；没有可选时空也应尽可能执行 | 玩家调整顺序；Spatial 可分别安排离场时空和跳过异象；零张可选时空仍置底并完成 |
| 持久化 | 失败不得推进；重试不得改变随机结果 | 候选状态先验证和保存，成功后才替换页面；失败重试同一对象或取消 |
| 中断 | 切后台、卸载、重开后能继续同一步 | 不以计时器承载提交；展示顺序、待处理来源、骰面、费用和一步撤销一起保存 |
| 恢复 | 不用静默重置掩盖读盘失败 | 读取失败可重试；损坏数据先备份成功才允许新局；未来版本禁止覆盖 |
| 呈现 | 看清当前步骤，按钮动作与结果一致 | 固定主操作、待处理列表、真实 disabled、完整离线卡文、卡图身份校验 |

## 四张特殊牌

- **乙太混沦 / Chaotic Aether**：遭遇本身不生效。成功结算一个遭遇触发后生效；仍有同实例触发在堆叠时不提前换出。离开异象不清除修正，离开任一时空才清除。反击不会执行效应。
- **境界交融 / Spatial Merging**：展示至两张时空，同时换入；其他展示牌任意顺序置底。遭遇触发的副本可在原异象离场后继续结算。原有多张时空的离场顺序也能指定。
- **艾蕾侬的树种核心 / Norn’s Seedcore**：混沌追加时空，保留已有时空；若旧来源在当前异象期间结算，异象仍会换出。进场引发混沌是独立、可反击或复制的触发；开局翻牌不触发。45 张时空全在场时仍能完成只展示异象的流程。
- **撒维尼亚沃土 / The Fertile Lands of Saulvinia**：只引发展示时空的混沌，展示牌全部置底，当前时空不变。若展示 Norn，其混沌后来从置底后的新牌库继续结算；不会误把 Norn 换入。

核对材料：本次逐条比对 50 张 Scryfall 简中印刷的 ID、中文名、类型、正文，未发现差异；这不等于保证将来的 Oracle 更新不影响中文印刷。

- [Wizards 官方完整规则，2026-08-19](https://media.wizards.com/2026/downloads/MagicCompRules%2020260819.txt)：116.2i、312.6、609.3、704.6f、901.5、901.7a、901.9、901.15。
- [March of the Machine Release Notes](https://magic.wizards.com/en/news/feature/march-of-the-machine-release-notes)：四张牌的处理与相关裁定。
- [Doctor Who Release Notes](https://magic.wizards.com/en/news/feature/magic-the-gathering-doctor-who-release-notes)：Start the TARDIS 等效应换境的反例。
- [Scryfall：MOC 简中时空与异象](https://scryfall.com/search?q=%28t%3Aplane+or+t%3Aphenomenon%29+lang%3Azhs+set%3Amoc)：固定集合范围。

## 界面取舍

服务于 `ux-goals.md` 的 B 一致性、D 状态反馈、E 恢复、G 阅读和 H 诚实。

1. Planechase 加入共享暗色根选择器，修正继承边框在父级提前解析造成的浅色边框。界面按一致性反馈对齐混沌工具的背景、面板、布局间距和按钮；详见 [界面一致性记录](planechase-atlas-design.md)。
2. 卡名和完整规则在图片外独立排版；卡图失败仍可完成牌局。明确图层顺序，完整卡图有关闭、失败提示和重试。
3. 正文最小 14 CSS px，按钮最小 44×44 CSS px，底部操作栏考虑安全区。不能把所有设备上的 88rpx 都当作 44px。
4. 去掉随机结果的计时器提交依赖。背景恢复为与混沌工具相同的共享粒子组件，动画在组件生命周期中管理，牌局保存和恢复不依赖动画完成。
5. 异象、反击、复制和实体牌触发多出必要的结算确认。普通空白骰面仍可快速继续；不能为了减少点击而自动宣告一个真实堆叠已结算。

## 验证结果与限度

- 全仓 JavaScript 语法检查：104 个文件。
- 全仓自动化测试：320 项通过，0 失败。相对原始基线新增 32 项，覆盖规则、真实页面控制器、存储边界和新视图的交互保护。
- 推荐严格诊断：100/100 位可达，deadCount 0，基准集 174,196 个画像。
- 使用本机微信工具附带的编译器完成 15 个 WXML、20 个 WXSS 文件的原生编译。此项只能证明编译通过，不能证明设备布局或 API 行为。
- 浏览器视觉预览使用实际页面控制器及原生 WXML 编译产物，在 320/375/430px 宽度抽查普通状态、展示排序、多时空、保存失败及卡图失败弹层。所查窄屏场景未见横向溢出，抽查启用按钮满足 44px 最小热区。它不是微信真机截图或正式端到端验证。
- 本机微信开发者工具 CLI 被关闭的服务端口阻挡；未将其改为开启，也未上传预览包或提交审核。
- 持久化模型拒绝超过 200 项待处理来源、100 条牌桌提示或非法数字的状态；页面提示先处理已有记录。此边界应在极端复制场景的实测中复核。
- 本轮不把该模块扩展为完整 MTG 模拟器。规则替代效应、控制权、玩家离场、额外套牌变体等没有完整自动裁定；使用范围需在产品定位评审中确认。
