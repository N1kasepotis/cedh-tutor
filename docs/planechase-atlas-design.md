# Planechase：界面一致性与结算交互

日期：2026-09-05。本轮根据用户的一致性反馈修订 `e4613ed` 的视觉方案。文件名保留，便于已有评审链接继续访问；当前实现以混沌工具及相邻功能页为参考。

## 当前设计决定

竞逐时空是对局中的功能页，背景、面板和按钮应遵循功能页的共享样式。移除独立图鉴色板、纸白规则页、直角按钮、巨型页眉和封面入口。

| 环节 | 当前实现 | 共享来源 |
| --- | --- | --- |
| 背景 | 黑色渐变、混沌工具紫粉强调色、相同粒子组件 | `dark-table.wxss`、`particle-background palette="random"` |
| 页面布局 | 全局页边距与间距；常规页标题、统计面板、圆角视图切换、卡牌面板 | `app.wxss`、`tokens.wxss` |
| 阅读区 | 暗色半透明面板、白色正文、柔和混沌强调区，保留完整规则 | `.surface`、共享 surface/accent token |
| 按钮 | 主操作直接继承 `.primary-button` 的背景、描边、圆角与内高光；其他控件使用共享输入底色和圆角 | 全局按钮与主题 token |
| 工具入口 | 与卷心菜、伊捷风暴并列的普通入口卡，相同内边距、标题字号、圆角和投影 | `.random-panel.surface.tool-entry` |
| 固定操作与弹层 | 仍使用不透字的深色底，卡面关闭、重试及完整文字可用 | 共享深色语义变量 |

标题采用现有衬线字体，正文沿用全局中文阅读字体；没有添加字体文件或新依赖。按钮最小热区仍为 44×44 CSS px，规则正文为 14px。粒子只是背景表现，牌局提交不等待动画。

## 文案与符号精简

2026-09-05 后续细修：删除页眉副标题、空状态的重复说明、通用按钮副文案与固定底栏装饰圆点；标题不带句号，排序编号与牌名分列，不使用 `1.` 拼接。反击与复制使用中文连接词；保留骰面、展开和排序等有实际含义的符号。

主按钮把「支付 0 点法术力」压缩为「免费」，付费时显示具体法术力数量，与动作词并排。底栏高度随之减小。操作记录改用简短结果，旧存档中的中点仅在显示时替换，不改写存档。卡牌官方文字、费用与时机限制、置底顺序语义和错误恢复操作保持完整。

本次验收覆盖普通读牌、空结算台、单一与多个触发、展示排序、设置、卡图失败和保存失败；沿用既有行为回归及原生编译。试用后重点收集简化文案是否引起结算对象或顺序误读，再补充必要的上下文提示。

## 微信原生样式差异修复（2026-09-06）

用户开发者工具截图暴露了普通浏览器预览未覆盖的问题：`style: v2` 的 `button:not([size=mini])` 默认宽度为 184px；`button[disabled]:not([type])` 的高优先级规则使用浅色背景。此前次级按钮没有覆盖前者，禁用规则又弱于后者，导致「新回合」挤压骰子读数、禁用按钮变白。已在本机官方 3.17.2 基础库的 `WAWebview.js` 中核对这两项规则。

- 在 Planechase 页面范围内覆盖原生宽度、自动外边距及禁用样式，其他模块不受影响。
- 读数与回合按钮改用独立列，结果文字不逐字折行；「空白改判」单独显示。
- 恢复核对与实体牌桌效应共用「牌桌待确认」，辅助说明降低为次级字号，移除单条事项末尾的空分隔线。
- 粒子保持混沌工具同色，透过独立背景层降至 22% 强度；正式卡文不删减。

本地预览已补入上述原生按钮 CSS、恢复对局与骰面改判场景，并支持 135% 字体压力检查。此前的浏览器通过记录仅证明普通 HTML 预览，不能作为微信默认样式下的验收证据。实际 Canvas 与最终微信渲染仍需开发者工具或手机复核。

本轮 320 项既有测试、104 个 JS 语法检查和严格诊断通过，15 个 WXML 与 20 个 WXSS 原生编译通过。带原生按钮 CSS 的预览在 320px 普通/放大字体下检查恢复、改判、未掷骰六组状态，并检查排序、多来源、保存失败和卡面弹层；375px 恢复状态与 430px 放大字体复核未见挤压。实际操作验证了确认待办后解锁新回合、点击新回合费用归零。

## 保留的交互约束

- 当前时空与结算台可切换；步骤改变后展示当前任务。多张时空均可读，多来源能力由玩家指定。
- 浏览卡文、展开复制/反击选项不改牌库、不写存档、不消耗撤销。
- 从卡文页进入待处理步骤时，第一次点击只展示结算内容。
- 单一来源可从底栏结算；多个来源不按显示顺序自动选取。
- 保存失败停留在已提交状态，重试同一候选；旧按钮连点不能执行新步骤。
- 卡图失败仍有占位和完整卡文。弹层打开与页面卸载后，背景操作及迟到的滚动回调受保护。

牌局 reducer、牌张快照及 schema 2 存档格式不变。完整 MTG 堆叠、实体牌状态和费用支付继续由牌桌裁定。

- 104 个 JavaScript 文件语法检查，320 项现有测试回归；无新增仅镜像 CSS 的测试。
- 15 个 WXML、20 个 WXSS 文件通过本机微信工具附带的原生编译器。
