# EDH 牌桌设计审查

本轮按用户要求先评分，再逐页重构。设计判据来自 bencium-controlled-ux-designer、README「视觉规则」「改动口径」及 docs/ux-goals.md；文案按 stop-slop 检查。下表是对照同一标准的设计自评，不代表外部团队或真机用户评分。

## 使用门槛与文案修正（2026-09-13）

用户反馈上一版限制过多、用语生硬。此前自评未充分反映这些问题，以下修正优先于后文的首轮设计记录：

- 署名、短评选填，选齐三张牌即可导出或分享；无署名海报显示“我的三张牌”
- 调牌不再要求关联套牌或写目标，可记同牌不同印刷版本的替换；去掉 100 条人为上限，默认随时复盘，关联战绩后才可选择按场数提醒
- 新桌默认允许代牌、无限组合技和额外回合；旧约定保持原值，不替玩家改已保存的选择
- 投票只需选择立场，赛制和理由收进选填区；未填赛制归入 unspecified，不推断为“两者都玩”，旧票数继续兼容；本地选择保存失败不再阻断在线投票
- 删除重复须知和说教提示，用“代表打法的牌”“没问题”“停止分享”等直接表达；保留影响操作结果的错误提示、官方禁牌范围和版本更新说明

新增回归检查覆盖无署名分享、空文字、选填投票信息及旧统计迁移。微信内容审核仍检查玩家填写的文字；牌张仍从真实印刷版本解析，所有权和投票去重保持原有行为。

| 维度 | 权重 | 原版 | 本轮 | 对应改动 |
| --- | --- | --- | --- | --- |
| 主任务与信息层级 | 20% | 6 | 8.5 | 删除首页口号和装饰序号，突出三张牌名片，工具入口分组 |
| 跨页面一致性 | 20% | 6 | 9 | 接入 dark-table 主题、全站字体、按钮 token 与 pressable-active |

加权自评从 5.6/10 提升至 8.7/10。剩余分数主要留给手机相册、真实弱网、双用户分享及长期使用反馈。

## 逐页修改

- **入口**：EDH 牌桌取代牌友空间；空名片展示示例牌面，已有完整玩家名片展示自己的选择。三张牌入口与四个工具分组，复盘继续进入原战绩页。
- **禁牌表**：43 张牌的真实印刷 ID 与卡图直链随包提供，进入列表不逐张请求元数据。二列整卡展示，点击进入完整卡图和投票。Lutri 保留仅限行侣的状态，不改变投票 ID 和历史票数。
- **名片**：三张独立选牌区，分别解释最佳设计、打法代表和常用妙妙牌。保留真实卡画、语言和短评；去除举报及其后端入口。
- **对局约定**：选项按标签与当前值排列，删除不承载功能的编号；保留版本变更后重新确认的说明。
- **调牌记录**：换出与换入并列显示卡图，观察状态和场数分行；编辑和战绩仍用同一数据来源。
- **开手讨论**：起手七张紧凑排列，座次与调度条件分行；讨论用留牌、调度、法术力、互动和组合技等现有词汇。

## README 对齐与取舍

| 项目要求 | 处理 |
| --- | --- |
| 网络图占位、延迟加载、高度确定 | 分包图片补齐 lazy-load 与暗色占位；整卡、缩略图和画廊明确高度；海报宽高由 750×1200 导出决定 |
| 按格子选择图片档位 | 禁牌二列卡面约 174 CSS px，3 倍屏约 522px，保留 normal 档；选牌弹层的小图使用 small 档并兼容旧记录 |
| 共用主题与反馈 | 金色强调集中在 dark-table；操作按钮消费 --cedh-btn-*；组件使用 apply-shared 接入全站按压反馈 |
| 微信原生按钮 | 局部显式 width、margin、禁用背景，避免 184px 默认宽度与白底 |
| 可读性与热区 | 功能文字满足 4.5:1 对比度目标；按钮与 picker 44px 下限；实际布局检查窄屏和放大字体 |
| 短提示与完整语义 | 自编 UI 去除装饰中点、圆点、句末点号与省略号；规则原文、牌名、网址、用户输入保留原样 |
| 删除功能的范围 | 删除举报按钮、处理器与云端 report 分支；保留内容审核、所有权检查和作者撤回 |
| 共用战绩 | 新区的对局复盘仍进入原 tracker，不另建战绩库 |
| 可回退与数据诚实 | 卡图失败显示占位并可重试；投票显示真实服务结果；未提交的本机选择不计入社区 |

服务 UX Goals A/B/F/G：突出任务、识别卡牌、统一反馈与提升可读性。代价是卡图比纯文字列表占空间和流量，通过静态索引与延迟加载控制请求；六页保留内容所需的结构差异，不强行做成相同表单。阅读页沿用竞逐时空已确立的无持续粒子背景取舍。

## Stop-slop 检查

自评 44/50：直接性 9、节奏 8、信任读者 9、自然度 9、信息密度 9。删除“牌局之外，也有好故事”等口号及重复解释；提示说明当前动作。保留主将、互动、妙妙牌等本项目与用户已使用的词，不凭语感发明术语。规则关键词与牌张正文不随视觉清理删改。

## 验收口径

2026-09-13 完成以下验证：

- `npm run check`：128 个 JavaScript 文件语法检查、335 项测试及严格推荐诊断通过，deadCount 为 0
- 微信原生编译：23 个 WXML、29 个 WXSS 通过；开发者工具 SDK 3.17.3 中六页运行无页面错误
- 布局：320/375/430px 的八种页面状态共 24 组检查通过；320px 使用 135% 字号，未发现检查范围内的文字溢出或小于 44px 的按钮；另查看原生截图
- 真实选牌：Sol Ring 搜索返回 10 项、简中印刷返回 20 项，所选语言及本机草稿恢复正确；海报成功导出为 750×1200
- 禁牌：原生列表 43 张牌，卡图失败状态与重试清理通过；Lutri 仍显示“维持行侣禁令”
- 云端：community 部署成功，状态 Active、超时 30 秒；真实调用已删除的 report 操作返回 `ok: false, code: INVALID_INPUT`；正常投票读取成功

开发者工具、浏览器布局验证、云函数部署和开发版上传分别留证。上述结果不代替手机相册、真实弱网和两位玩家的分享验收；开发版上传版本与源提交以交付回执为准。
